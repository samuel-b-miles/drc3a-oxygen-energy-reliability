# Public Release Staging

This directory is for planning a later public clone or publication-reference repository.

The public version should contain:

- source code required to reproduce accepted tables and figures
- aggregate outputs needed for inspection
- data dictionaries and provenance notes
- synthetic, anonymized, or restricted-access data instructions
- exact environment and run instructions

The public version should not contain:

- raw survey submissions
- respondent-level records
- facility-identifying free text
- collaborator-only documents
- unpublished third-party PDFs or manuscript drafts
- access tokens, credentials, or private Drive exports
