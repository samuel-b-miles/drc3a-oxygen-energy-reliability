# Sources

Human-readable source material and source indexes for the manuscript.

Use this directory for lightweight, versionable records:

- literature coverage CSVs
- source bibliographies
- source-to-claim maps
- notes on canonical PDFs or seed documents

Do not commit copyrighted PDFs, raw manuscript drafts, or private collaborator documents unless explicitly approved. Store those in Google Drive and link them from `docs/drive-index.md`.
